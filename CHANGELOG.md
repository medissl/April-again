# 1.0.0 — 23 November 2026

- Five complete routes, 75 encounters, 225 choices and 15 illustrated endings.
- Point-and-click school navigation, orientation, routines, home/day progression,
  journal appointments, atomic saves, read-only skipping and persistent CG gallery.
- Nunito ExtraBold throughout; centered speaker ribbons and a calendar with location
  inside its panel. The main menu uses the school gate without characters.
- Replaced malformed generated buttons with original editable vector UI. Slider fills
  start flush with their tracks. Choices use full-height character staging.
- Removed duplicate map captions, nested door buttons, white hover washes and
  off-camera door targets. Door hit regions follow the visible architecture.
- Silent dialogue advancement, retained menu cues, licensed quiet door and rain audio.
- Fixed hidden title controls after ending credits. Added full controller playthroughs
  and rendered layout review at 1080p and 720p.
- Custom application icon, disabled Unity splash, Windows portable ZIP and per-user
  installer. Saves are preserved by uninstallation.
- Corrected system-panel margins: inset headings/close controls, dedicated map
  header, spaced content/footer areas, measured help popups and centered item art.
