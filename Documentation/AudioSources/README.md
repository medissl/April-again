# Audio provenance

The user explicitly authorized reusing audio from their earlier games and downloading missing audio for this project.

- `Assets/AprilAgain/Audio/Interface/hover.wav`, `select.wav`, `open.wav`: MENFENG menu cues from the user's local `menfeng-audio-clean/assets/audio`, reused under the creator's explicit authorization in this conversation. These are not relabeled CC0. Other MENFENG foley with unresolved upstream source notes is not redistributed here.
- `back.ogg`, `save.ogg`, `error.ogg`: Kenney Interface Sounds, CC0. Publisher: https://kenney.nl/assets/interface-sounds . The original downloaded archive and License.txt are retained beside this document.
- `Assets/AprilAgain/Audio/World/room_door.ogg`: `doorOpen_1.ogg` from Kenney RPG Audio, CC0. Publisher: https://kenney.nl/assets/rpg-audio . The archive and original license are retained locally. This plays quietly only for visible indoor door travel.
- `Assets/AprilAgain/Audio/World/rain_window.wav`: alxl, Rain on Window Loop, using the publisher's CC0 option. https://opengameart.org/content/rain-on-window-loop . See `Rain-License.txt`.
- Five original music tracks were synthesized locally by `Tools/Art/build_audio.py`. Retired synthetic world effects remain as production sources but are excluded from the runtime catalog and release. Dialogue reveal and advance are silent.
- Kenney Voiceover Pack was downloaded and inspected: https://kenney.nl/assets/voiceover-pack . It contains male/female game-announcer phrases, not five distinct female conversational performances. It is not included as character voice acting. The game is intentionally playable without voices.

Both Kenney archives were obtained through their public publisher download flow. Files named `kenney_interface-sounds.zip` and `kenney_voiceover-pack.zip` from the first attempt are HTML responses, not usable archives; the valid downloads have `_download.zip` names.
